# 📊 Electronic Sales Analysis Dashboard – Power BI

## 📌 Project Overview
The Electronic Sales Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It provides insights into electronic product sales, customer purchasing behaviour, transaction performance, and product trends. The dashboard helps analyze sales data and identify patterns that support data-driven business decisions.

## 🎯 Key Features
- **Sales Overview:** Track Total Sales, Total Quantity, Total Transactions, and Average Sales.
- **City-wise Analysis:** Analyze sales performance across different cities using map visualization.
- **Product Analysis:** Compare sales performance across different mobile models.
- **Payment Analysis:** Understand customer payment preferences through payment method distribution.
- **Customer Ratings:** Analyze customer ratings to understand satisfaction patterns.
- **Time-based Trends:** Monitor daily and monthly sales and quantity trends.
- **Brand Performance:** Compare brands based on sales, quantity, and transactions.
- **Interactive Filters:** Use slicers to filter data by mobile model, date, day, and payment method.

1. Understand overall electronic sales performance.
2. Identify top-performing mobile models and brands.
3. Analyze customer payment preferences.
